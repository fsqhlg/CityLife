## 1. 必敲：`RedisIdWorker.nextId`

**文件**：`src/main/java/com/hmdp/utils/RedisIdWorker.java`
**考什么**：位运算拼接、按天分 key、时间戳起点。

```java
@Component
public class RedisIdWorker {

    // 起始时间戳（秒）：2022-01-01 00:00:00 UTC
    private static final long BEGIN_TIMESTAMP = 1640995200L;

    // 序列号占 32 位
    private static final int COUNT_BITS = 32;

    @Resource
    private StringRedisTemplate stringRedisTemplate;

    public long nextId(String keyPrefix) {
        // 1. 当前时间戳（秒） - 起始时间戳
        long timestamp = Instant.now().getEpochSecond() - BEGIN_TIMESTAMP;

        // 2. 按天生成 Redis 自增序列号，key 形如 icr:order:2026:10:29
        String date = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy:MM:dd"));
        long count = stringRedisTemplate.opsForValue().increment("icr:" + keyPrefix + ":" + date);

        // 3. 拼接：时间戳左移 32 位，再按位或上序列号
        return timestamp << COUNT_BITS | count;
    }
}
```

### 手敲提示

- 必须是 `<< 32` 再 `| count`，不能加法（会进位污染时间戳部分）；
- 时间戳用 `Instant`，别用 `LocalDateTime.toEpochSecond(ZoneOffset.UTC)`（会偏 8 小时）；
- 序列号 key 按天分，方便统计每日单量。

### 验收

```
订单号 653920431652208651
高 32 位 = 订单号 >> 32  → 约 152252715（对应 2026-10-29）
低 32 位 = 订单号 & 0xFFFFFFFF → 当天第几个
```

## 2. 必敲：`seckill.lua`

**文件**：`src/main/resources/seckill.lua`
**考什么**：Lua 原子性、`tonumber`、`SISMEMBER`、`INCRBY`、返回值约定。

```lua
-- 参数：ARGV[1] = 优惠券 id，ARGV[2] = 用户 id
-- 返回：0 成功；1 库存不足；2 重复下单；3 库存未预热

local voucherId = ARGV[1]
local userId = ARGV[2]

local stockKey = 'seckill:stock:' .. voucherId
local orderKey = 'seckill:order:' .. voucherId

local stock = tonumber(redis.call('get', stockKey))
if stock == nil then
    return 3
end
if stock <= 0 then
    return 1
end
if redis.call('sismember', orderKey, userId) == 1 then
    return 2
end

redis.call('incrby', stockKey, -1)
redis.call('sadd', orderKey, userId)
return 0
```

### 手敲提示

- `ARGV` 下标从 1 开始；
- 一定要先 `tonumber` 再判 nil，否则 `nil <= 0` 直接报错；
- 判断顺序：库存预热 → 库存 → 重复下单 → 扣减；
- `SISMEMBER` 返回 0/1，不是 true/false；
- 不要在脚本里用 `KEYS`，参数从 `ARGV` 拿。

### 验收

```
redis-cli --eval seckill.lua , 10 1     （先手动设置 seckill:stock:10 = 3）
返回 0，库存变 2，Set 里多了用户 1
再执行一次 → 返回 2
库存改成 0 → 返回 1
删除 stock key → 返回 3
```

## 3. 必敲：`VoucherOrderServiceImpl`

**文件**：`src/main/java/com/hmdp/service/impl/VoucherOrderServiceImpl.java`

### 3.1 字段与初始化

```java
@Resource
private ISeckillVoucherService seckillVoucherService;

@Resource
private RedisIdWorker redisIdWorker;

@Resource
private StringRedisTemplate stringRedisTemplate;

/**
 * 自己注入自己（拿到 Spring 代理对象），异步线程里事务才会生效
 */
@Resource
private IVoucherOrderService proxy;

private static final DefaultRedisScript<Long> SECKILL_SCRIPT;

static {
    SECKILL_SCRIPT = new DefaultRedisScript<>();
    SECKILL_SCRIPT.setLocation(new ClassPathResource("seckill.lua"));
    SECKILL_SCRIPT.setResultType(Long.class);
}

private static final ExecutorService SECKILL_ORDER_EXECUTOR = Executors.newSingleThreadExecutor();

private final BlockingQueue<VoucherOrder> orderTasks = new ArrayBlockingQueue<>(1024 * 1024);

@PostConstruct
private void init() {
    SECKILL_ORDER_EXECUTOR.submit(new VoucherOrderHandler());
}
```

**注意**：

- `proxy` 不能省，否则 `@Transactional` 在异步调用里失效；
- `@PostConstruct` 让消费线程随应用启动；
- 队列用有界队列，防止内存打爆。

### 3.2 消费线程

```java
private class VoucherOrderHandler implements Runnable {
    @Override
    public void run() {
        while (true) {
            try {
                // 1. 队列为空时阻塞
                VoucherOrder voucherOrder = orderTasks.take();
                // 2. 创建订单
                handleVoucherOrder(voucherOrder);
            } catch (Exception e) {
                log.error("处理订单异常", e);
            }
        }
    }
}

private void handleVoucherOrder(VoucherOrder voucherOrder) {
    // Lua 已保证一人一单，这里直接落库，数据库层再兜底
    proxy.createVoucherOrder(voucherOrder);
}
```

**注意**：`take()` 会阻塞，`poll()` 不会；循环里必须 catch，否则线程挂了就没人消费。

### 3.3 秒杀入口

```java
@Override
public Result seckillVoucher(Long voucherId) {
    // 1. 获取当前用户
    UserDTO user = UserHolder.getUser();
    if (user == null) {
        return Result.fail("请先登录");
    }
    Long userId = user.getId();

    // 2. 生成全局唯一订单 id
    long orderId = redisIdWorker.nextId("order");

    // 3. 执行 Lua：库存判断 + 一人一单 + 扣库存
    Long result = stringRedisTemplate.execute(
            SECKILL_SCRIPT,
            Collections.emptyList(),
            voucherId.toString(),
            userId.toString(),
            String.valueOf(orderId)
    );

    int r = result == null ? -1 : result.intValue();
    if (r != 0) {
        return Result.fail(r == 1 ? "库存不足！" : r == 2 ? "不能重复下单！" : "秒杀活动不存在！");
    }

    // 4. 扣减成功，订单入队
    VoucherOrder voucherOrder = new VoucherOrder()
            .setId(orderId)
            .setUserId(userId)
            .setVoucherId(voucherId);
    orderTasks.add(voucherOrder);

    // 5. 立即返回订单 id
    return Result.ok(orderId);
}
```

**注意**：

- `execute` 的第二个参数是 `KEYS` 列表，这里为空；`ARGV` 依次传入；
- ID 在 Lua 之前生成，失败的请求也会消耗序号（正常）；
- 入队后立即返回，**不要**在这里写库。

### 3.4 落库

```java
@Override
@Transactional
public void createVoucherOrder(VoucherOrder voucherOrder) {
    Long userId = voucherOrder.getUserId();
    Long voucherId = voucherOrder.getVoucherId();

    // 1. 数据库兜底：再查一次是否重复下单
    long count = query()
            .eq("user_id", userId)
            .eq("voucher_id", voucherId)
            .count();
    if (count > 0) {
        log.error("用户 {} 已经购买过优惠券 {}", userId, voucherId);
        return;
    }

    // 2. 扣减库存（带 stock > 0 条件，防止超卖）
    boolean success = seckillVoucherService.update()
            .setSql("stock = stock - 1")
            .eq("voucher_id", voucherId)
            .gt("stock", 0)
            .update();
    if (!success) {
        log.error("优惠券 {} 库存不足", voucherId);
        return;
    }

    // 3. 写入订单
    save(voucherOrder);
}
```

**注意**：

- `setSql("stock = stock - 1")` + `gt("stock", 0)` 是防超卖的关键；
- 顺序：先查重，再扣库存，最后插订单；
- 方法必须是 `public`，且通过 `proxy` 调用，事务才生效。

## 4. 顺手敲：库存预热

**文件**：`src/main/java/com/hmdp/service/impl/VoucherServiceImpl.java` 的 `addSeckillVoucher`

```java
// 保存秒杀信息
seckillVoucherService.save(seckillVoucher);

// 把库存预热到 Redis，秒杀 Lua 脚本会直接读这个 key
stringRedisTemplate.opsForValue().set(
        SECKILL_STOCK_KEY + voucher.getId(),
        String.valueOf(seckillVoucher.getStock()));
```

**注意**：没这行，Lua 里 `get` 返回 nil，所有请求都提示「秒杀活动不存在」。

## 5. 验收（完整链路）

```
1. 启动 Redis、MySQL、应用
2. POST /voucher/seckill 创建一张 stock=3 的券（会同时写 Redis 库存）
3. 登录 3 个用户，分别 POST /voucher-order/seckill/{id}
   → 3 个都成功，返回订单 id
4. 同一个用户再点一次
   → "不能重复下单！"
5. redis-cli get seckill:stock:{id}      → 0
   redis-cli scard seckill:order:{id}    → 3
6. 等 1~2 秒，查 tb_voucher_order        → 3 条
   tb_seckill_voucher.stock               → 0
7. 再来 6 个用户并发抢一张 stock=3 的新券
   → 成功 3、失败 3，不超卖
```
